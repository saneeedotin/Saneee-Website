# The Sanity Machine

The latest saneee.in redesign prototype. It is a standalone page, separate from the Next.js site in the rest of this repository.

Run it from this folder with any static server, for example:

```bash
npx serve .
```

Before launch, change the link preview addresses (`og:url`, `og:image`) in `index.html` from the temporary Firebase address to saneee.in.
